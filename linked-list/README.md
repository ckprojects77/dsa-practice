# Linked List

| # | Problem | Difficulty | Approach | Time | Space |
|---|---|---|---|---|---|
| 1 | Reverse Linked List | Easy | Iterative | O(n) | O(1) |
| 2 | Merge Two Sorted Lists | Easy | Two Pointers | O(n+m) | O(1) |
| 3 | Linked List Cycle | Easy | Floyd's Algorithm | O(n) | O(1) |
| 4 | Remove Nth Node From End | Medium | Two Pointers | O(n) | O(1) |
| 5 | Reorder List | Medium | Find Middle + Reverse + Merge | O(n) | O(1) |
| 6 | LRU Cache | Medium | HashMap + Doubly Linked List | O(1) | O(n) |
